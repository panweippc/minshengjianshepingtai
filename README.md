# 民生建设平台 (minshengjianshepingtai)

民生建设平台项目仓库。

## 分支协作模型

- 每位成员各自使用独立的功能分支进行开发。
- 成员完成开发后，将其分支内容合并到 **`pan`** 分支（项目负责人的集成分支）。
- 项目负责人（`pan`）审核后，将 `pan` 合并到 **`main`** 主分支。
- 其他成员直接拉取 `main` 或 `pan` 的最新代码即可同步。

## 当前状态

- 默认开发/集成分支：`pan`
- 主分支：`main`（由 `pan` 合并而来）
- 本仓库初始提交由 Maven 包装文件构成，作为项目骨架种子。
